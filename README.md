# 📄 AI Resume Analyzer

An intelligent resume analysis application that compares a candidate's resume with a job description.

## 🚀 Features

- Upload resume in PDF format
- Extract text from resumes
- Detect technical skills
- Compare resume skills with job requirements
- Identify matching skills
- Identify missing skills
- Calculate skill match percentage
- Calculate text similarity using TF-IDF
- Generate an overall resume-job match score

## 🛠️ Technologies

- Python
- Streamlit
- Scikit-learn
- TF-IDF
- Cosine Similarity
- PyPDF

## 🧠 How It Works

The application follows this process:

1. User uploads a PDF resume.
2. Text is extracted from the PDF.
3. Technical skills are detected.
4. The job description is analyzed.
5. Resume skills are compared with required skills.
6. TF-IDF is used to measure textual similarity.
7. A combined match score is generated.

## 📊 Scoring

The current scoring system uses:

- 60% technical skill match
- 40% text similarity

This scoring system is a starting point and can be improved in future versions.
